# Technical SEO Fundamentals

Technical SEO refers to website and server optimizations that help search engine crawlers effectively crawl and index a site, without directly involving the content itself. Even excellent content will fail to rank if the underlying site has serious technical problems.

Site speed is a confirmed ranking factor for both desktop and mobile search. Core Web Vitals, a set of metrics introduced by Google, measure loading performance (Largest Contentful Paint), interactivity (Interaction to Next Paint), and visual stability (Cumulative Layout Shift). Pages should aim for a Largest Contentful Paint under 2.5 seconds.

Mobile-friendliness is essential because Google uses mobile-first indexing, meaning it primarily uses the mobile version of a site's content for indexing and ranking. A responsive design that adapts to different screen sizes is the standard approach.

A clean site architecture with a logical folder structure, an XML sitemap submitted to Google Search Console, and a properly configured robots.txt file all help search engines crawl a site efficiently. Broken links (404 errors) and redirect chains should be minimized, as they waste crawl budget and create a poor user experience.

HTTPS (secure, encrypted connections) has been a lightweight ranking signal since 2014 and is now considered a baseline requirement rather than an advantage, since most browsers flag non-HTTPS sites as "not secure."

Structured data, implemented via Schema.org markup, helps search engines understand page content in more detail and can enable rich results in the search listings, such as star ratings, FAQs, or event details.
