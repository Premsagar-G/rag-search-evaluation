# On-Page SEO Essentials

On-page SEO refers to the practice of optimizing individual web pages in order to rank higher and earn more relevant traffic in search engines. On-page refers to both the content and HTML source code of a page that can be optimized, as opposed to off-page SEO which refers to links and other external signals.

The title tag is one of the most important on-page elements. It should be under 60 characters, include the primary target keyword near the beginning, and accurately describe the page content. Meta descriptions, while not a direct ranking factor, strongly influence click-through rate from the search results page and should be under 155 characters.

Header tags (H1 through H6) create a content hierarchy that helps both users and search engines understand the structure of a page. Each page should have exactly one H1 tag that includes the primary keyword, and subsequent H2 and H3 tags should organize supporting subtopics.

Image optimization matters for both SEO and page speed. Every image should have a descriptive alt text attribute for accessibility and SEO, and files should be compressed to reduce load time. Slow-loading pages tend to rank lower and have higher bounce rates.

Internal linking connects related pages within the same website, distributing "link equity" and helping search engines discover and understand the relationship between pages. A well-structured internal linking strategy can meaningfully improve rankings even without acquiring new backlinks.

URL structure should be short, descriptive, and include the target keyword where natural, for example example.com/social-media-services rather than example.com/page?id=482.
